# 기획안 양식 분석 (구글 시트 / 슬라이드)

두 문서는 용도가 다르다. 어드민은 **하나의 입력 → 두 산출물**로 뽑아야 한다.

---

## A. 시트형 = 디자인·퍼블 작업 요청서
샘플: 24년 9월 <모바일 B tv가 쏩니다> / 탭 `모바일Btv`

### A-1. 머리말 블록
- 1행: `YYYY M월 이벤트 프로모션`
- 2행: `<이벤트명> | M.D (요) ~ M.D (요)`

### A-2. 작업 항목 체크표 (가로 1행, o / - 표기)
| 빅배너 | 이벤트배너 | 띠배너 | 상세 | 팝업 | MMS | 1단 메뉴카드 | 2단 메뉴카드 |
- 바로 아래에 applink URL 1줄
  `http://mobilebtv.com:8080/view/v3.0/applink?type=event_url&id=<업로드번호>`

### A-3. 작업 요청서 — 항목별 카피 블록
항목(빅배너 / 이벤트 배너 / 띠배너 / 상세 / 팝업 / MMS / 메뉴카드)마다 한 행:
- 좌: 항목명
- 중: 배너용 짧은 카피 (3~4줄: 월/이벤트명/기간)
- 우: 상세 본문 전문 (제목, 기간, 리드, 혜택 나열, 참여 방법 단계, 버튼 문구, 주석)
- 우측 여백: `ID: NA00000000000`, 딥링크(예: `btvplus://fast_ch`)

### A-4. 경품표
메뉴카드 단수별로 열이 갈린다.
| 경품 (1단) | 당첨자수 | 경품 (2단) | 당첨자수 |
- 하단: `당첨자 발표일: M월 D일 (요)`

### A-5. 개인정보 취합 사항 (펼치기 영역)
고정 문구 3종 + 이벤트명만 치환:
1. 개인정보 **수집·이용** 동의서 — 수집/이용 목적 · 수집 항목 · 보유기간 3열 표
2. 개인정보 **처리위탁** 동의서 — 수탁사 (예: SK 엠앤서비스)
3. 개인정보 **제3자 제공** 동의서 — 제공받는 자 · 목적 · 보유기간 3열 표
- 각 블록마다 `ㅁ 동의` 체크 + 거부권 고지 주석

### A-6. 유의사항
불릿 5~6개. 대부분 고정, 경품 유형에 따라 일부 교체.

## B. 슬라이드형 = 시안·수정 커뮤니케이션 덱
샘플: 25년 8월 <매일매일 혜택이 터져써머> 수정 기획안 (16장)

### 장 구성
| # | 장 | 내용 |
|---|---|---|
| 1 | 표지 | 이벤트명 / `수정 기획안(YYMMDD)` |
| 2 | 간지 | `모바일 B tv 기획안` |
| 3 | 수정 내용 요약 | 변경점 불릿 (신규 기획안이면 생략) |
| 4 | 영역별 카피 | `<영역명>` + 카피, 영역 순서 지정, 딥링크·이벤트ID·정책번호 |
| 5 | 퍼블 요청 사항 | zip 파일명, 이벤트ID, 정책번호, 출석 횟수, **팝업 문구 N행 표** |
| 6 | 이벤트 배너 | 빅배너 / 1.5단 블록 — 카피 + 기간 |
| 7 | 간지 | `B tv 기획안` (TV 매체 분리) |
| 8~ | 매체별 시안 | TDB, 팝업 시안(+수정/예비), 3단배너 1·2, 롱배너, MMS, 2단배너 |

### 장마다 반복되는 슬롯
- 영역/매체명 (제목)
- 메인 카피 / 서브 카피 / 보조 문구
- 버튼 문구
- 주석 (`*…`)
- 경품 요약 (상품명 + 인원)
- 이미지 자리 표시 (`상품권 이미지`, `모비 캡쳐 화면` 등)

## C. 현재 schema.js 와의 차이 — 추가로 필요한 입력
| 필요 데이터 | 현재 | 비고 |
|---|---|---|
| 작업 항목 체크 (8종 o/-) | 없음 (channels 만 있음) | A-2, 배너 체크리스트와 통합 가능 |
| 영역별 카피 블록 (메인/서브/본문/버튼/주석) | 없음 | A-3, B 전 장에서 재사용 |
| 경품 리스트 (상품명·인원·메뉴카드 단수) | 없음 | A-4, B 요약 |
| 당첨자 발표일 | 없음 | A-4 |
| 개인정보 3종 동의 (수탁사·제공받는자·보유기간) | `privacyAgreement` 불린만 | A-5 |
| 유의사항 불릿 | 없음 | A-6 |
| 딥링크 / applink 업로드 번호 | launch 유형만 | A-2 |
| 출석체크 회차별 팝업 문구 | 없음 | B-5, 출석체크 유형 필수 |
| 참여 방법 단계 안내 | 없음 | A-3 상세 |
| 문서 버전 (`수정 기획안(YYMMDD)`) | 없음 | B-1 |
